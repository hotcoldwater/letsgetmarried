# Pretendard

`PretendardVariable.ttf`는 Pretendard Variable, Version 1.309의 수정하지 않은 로컬 폰트 파일입니다. 네트워크 없이 디자인 시안을 표시하기 위해 포함했습니다. 로컬에 있던 동일 폰트와 라이선스 사본을 사용했습니다.

- 공식 프로젝트: https://github.com/orioncactus/pretendard
- 라이선스: SIL Open Font License 1.1, 동봉한 `OFL.txt` 참조
- 브라우저 CSS 이름: `Pretendard`
- 지원 굵기: 가변 폰트

현재 전체 TTF는 약 6.4 MB입니다. 배포 준비 단계에서 공식 웹용 WOFF2/서브셋을 검토해 초기 다운로드 크기를 줄입니다.
